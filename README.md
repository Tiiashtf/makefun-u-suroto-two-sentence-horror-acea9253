One original two-sentence horror story, written by a small deterministic program to `/output/entry.txt`:

> Every night since we brought the baby home, our dog has barked at the same corner of the nursery. Tonight he stopped, and the baby started barking back.

The setup is an ordinary new-parent detail — a dog barking at one corner of the nursery, night after night. The second sentence turns it: the dog has gone quiet, and the baby has taken up the barking, so whatever was in the corner is no longer outside the crib. The horror is implied, never explained; 152 characters, exactly two sentences.

## Run it

```sh
python3 main.py
```
